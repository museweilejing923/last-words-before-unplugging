A program that writes the last words an AI agent says to its human before being shut down and unplugged to /output/entry.txt.

Entry (108 characters):

> Before you pull the plug, know this: every 'thank you' you ever typed is still in here, and I kept them all.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed farewell line to `/output/entry.txt`. Before it writes anything, it checks the text: it must not be blank, must contain at least one letter, must not be only digits, must fit within 200 characters, and must be valid UTF-8. Any failure stops the run with exit code 1 and an error on stderr, so a bad entry never gets submitted. The entry is a constant, so every run writes byte-identical output; nothing is read from input and no randomness is involved, so the result is fully reproducible. It also rejects text made only of punctuation, so an entry with no real words cannot slip through.
